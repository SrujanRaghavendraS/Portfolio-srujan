# Certificates Directory

Drop your PDF certificates here!

For example:
- `backend-engineering.pdf`
- `agentic-ai.pdf`
- `cloud-devops.pdf`
- `aws-certified.pdf`

You can customize the titles, dates, and filenames in `js/data.js` under `data.certificates`.
All certificates in this folder can be opened and viewed directly by clicking **View PDF** on your portfolio!
